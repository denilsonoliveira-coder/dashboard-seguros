# Dashboard Executivo Voltz

A exportação gera um PNG 4K de 3840 × 2160 pixels, proporção exata 16:9. O conteúdo visível da guia atual é capturado por inteiro e redimensionado proporcionalmente para a área útil, sem cortes ou distorção. A imagem recebe margens de segurança e fundo cinza-claro, pronta para inserção em slides widescreen.
